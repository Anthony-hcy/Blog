# 问题记录

本文档记录通过浏览器实际访问本站时发现的问题、根因与修复状态。每次检查追加一节。

## 2026-10-03 站点检查

通过浏览器（Edge + 该站 Service Worker）访问 `https://anthony-hcy.github.io/Blog/` 全面检查，发现以下问题。

### 问题 1：About 页 VIEWS 统计显示 `–`（不蒜子统计失败）

- **现象**：About 页「SITE STATS → VIEWS」显示 `–`。
- **根因**：第三方统计服务 `busuanzi.ibruce.info` 的 JSONP 请求失败——控制台报
  `ERR_CONNECTION_CLOSED` 与 `ERR_BLOCKED_BY_ORB`（Opaque Response Blocking，浏览器
  安全机制拦截了跨域响应）。属于第三方服务不稳定/被浏览器拦截，非本站代码 bug。
- **现状**：`layout.js` 已有 8 秒 watchdog，把占位符降级为 `–`（避免显示误导性的 0），
  降级逻辑本身正确。**保留现状**，不修（第三方服务不可控）。
- **可选项**：若要恢复真实统计，需更换方案（如自托管 umami 或改用其它计数器），
  暂不做。

### 问题 2：「小作文」分类计数不一致（14 vs 15）

- **现象**：主页 / 归档页 / 分类页侧栏显示「小作文 14」，而文章页 / Portal 显示
  「小作文 15」；Portal 侧栏分类合计 37 ≠ 总帖数 36。
- **根因（两层）**：
  1. 仓库曾存在一篇测试文章 `content/posts/post-1790995699522.md`
     （`category: 小作文`，`draft: false`），会参与构建计数；该文件已于
     `919ba9e`（2026-10-03 15:18）删除。删除后全站（含 curl 直连线上）
     分类计数一致为 14。
  2. 浏览器仍显示 15 的根因：`sw.js` navigate 分支误用
     `staleWhileRevalidate`——**先返回缓存旧页面、后台再更新**，导致部署新版本后
     用户继续看到旧页面 / 旧分类计数，直到后台更新 + 版本检查（version.json）触发
     刷新才纠正。而 `sw.js` 顶部注释明确承诺「页面导航：network-first（内容永远最新）」，
     实现与注释不符。
- **修复**：`c138718` 将 `sw.js` navigate 分支改回 `networkFirst`
  （网络可用时永远返回最新内容并更新缓存，断网才回退缓存），与注释一致。
  部署后 curl 与浏览器均应为 14。

### 问题 3：window.load 被懒加载图片延迟约 120 秒，SW 注册被推迟

- **现象**：每次导航等待 `load` 事件超时；控制台提示
  `Images loaded lazily and replaced with placeholders. Load events are deferred.`；
  `performance` 实测 `load_ms` 达约 121 秒。观察窗口内 `sw.js` 请求长时间不出现。
- **根因**：全站图片 `loading="lazy"`，Edge 将 `load` 事件推迟到懒加载图片
  完成；而 `layout.js` 的 SW 注册挂在 `window.load` 上，首访用户在此期间不受
  SW 控制。
- **修复**：`c138718` 将 `initServiceWorker` 的注册时机从 `window.load` 提前到
  `DOMContentLoaded`（模块执行时 DOM 已可交互则直接注册）。

### 问题 4：version.json 首次加载瞬时失败

- **现象**：首次硬刷新时 `version.json?t=...` 报一次 `ERR_FAILED`；随后抓包中
  返回 200（内容 `{"v":"2026-10-03T07:18:33.776Z"}`）。
- **根因**：偶发网络抖动；`layout.js` 的 `initContentRefresher` 已 `catch` 静默
  处理（断网不打扰），且 version.json 请求带 `cache:'reload'`。
- **现状**：无实际影响，不修。

### 可忽略项

- 控制台 `chrome-extension://invalid/` 的 `ERR_FAILED` 来自浏览器扩展（如 iTab）
  的内容脚本，与本站无关。

### 检查结论

- 页面渲染、无限滚动（4 页全加载）、搜索（ExSearch）、PhotoSwipe、字体
  （npmmirror）均正常；本站全部资源 200。
- 需要修复的代码问题为问题 2（SW navigate 缓存策略）与问题 3（SW 注册时机），
  已在 `c138718` 一并修复。
